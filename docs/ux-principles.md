# UX Principles

1. Speed is the ultimate feature
2. GUI first, always keyboard. 
3. Use Command bar and Context Menu
4. Simple should be easy, complex should be possible. This means always start with Opiniated Defaults, always allow configuration
5. Simple first, then powerful (Linear)



For frontend, always start with default Nuxt UI components. The more of the UX details we can offload to Nuxt UI the better. 



Decisions
Decide and move on (Linear)
Always try to make the decision a two way door, and just make the call
